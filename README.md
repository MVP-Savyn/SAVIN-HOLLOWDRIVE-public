## 📖 Acerca de HollowDrive

**HollowDrive** es una herramienta moderna diseñada para simplificar y elevar al máximo nivel la experiencia de preparar unidades USB de rescate, instalación y mantenimiento técnico. 

A través de una interfaz gráfica intuitiva, rápida y fluida, HollowDrive te permite instalar un sistema multiboot completo, personalizar su apariencia y descargar e integrar automáticamente paquetes de utilidades, herramientas de diagnóstico y sistemas operativos sin configuraciones complicadas.

---

## ✨ Características

- 🚀 **Instalación Asistida en 1 Clic**: Detección inteligente de pendrives y discos externos, formateo seguro y particionado óptimo (soporte UEFI/BIOS y esquemas GPT/MBR).
- 📦 **Catálogo de Addons Comunitarios**: Descarga e instala paquetes de utilidades, antivirus offline, rescatadores y live OS categorizados y verificados.
- 🎨 **Personalización Visual**: Temas interactivos, fondos dinámicos y personalización estética para tu menú de arranque.
- 🛡️ **Validación de Integridad**: Comprobación hash y verificación automática de descargas para garantizar que cada archivo llegue libre de errores.
- ⚡ **Rendimiento Nativo**: Diseñado para una ejecución fluida, sin dependencias pesadas y optimizado para Windows 10 y 11.

## 📋 Requisitos del Sistema

- **Sistema Operativo**: Windows 10 o Windows 11 (64-bit).
- **Permisos**: Privilegios de Administrador (necesarios para gestionar y particionar unidades de almacenamiento masivo).
- **Memoria USB**: Pendrive o disco externo de al menos 8 GB (recomendado 32 GB o más para almacenar múltiples sistemas y herramientas).
- **Conexión a Internet**: Necesaria para la descarga de addons y sincronización del catálogo.
